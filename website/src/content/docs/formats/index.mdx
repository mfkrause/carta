carta names formats the way pandoc does, so a command written for one runs against the other. A
format name may carry extension toggles (`markdown+hard_line_breaks-raw_html`), and
`carta --list-extensions=<format>` prints the set a given format accepts.

Compatibility is measured against pandoc {meta.pandocVersion} (`pandoc-api-version`
{meta.astVersion}).

## Formats

- ✅ **Usable:** basically done. Any remaining parity gaps are minor and unlikely to affect regular
  use.
- 🚧 **In development:** large parity gaps or breaking issues. Not recommended for use yet.
- ❌ **Not started.**
- ➖ **Not applicable:** pandoc has no such direction.

## Extensions

The reader acts on the **Supported** set below. Every other name in a format's accepted set is a
recorded no-op toggle, so a format spec that names one still parses. A `+`/`-` toggle that names
anything outside the accepted set is rejected.
