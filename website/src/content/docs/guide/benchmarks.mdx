## How to read this

Both tools run with identical `-f/-t` flags; pandoc is configured so both tools produce equivalent
output and do equivalent work. Times are wall-clock end-to-end (process start included). `speedup` =
pandoc mean ÷ carta mean. `MB/s` is carta throughput over the actual input size. RSS is peak resident
memory from a single `/usr/bin/time` run. The HTML and LaTeX targets include syntax highlighting of
code blocks in both tools.

Reproduce with `tools/bench-suite/run.sh all`. Numbers are machine-specific; yours will differ.
